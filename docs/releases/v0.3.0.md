> **Status: draft.** This entry rolls up what has merged to main since

## Agent runtimes & the AgentMesh

- **Three new conformant runtimes:**
  - **vibe** — Mistral's coding agent: dedicated shim engine, service-account credentials on MISTRAL_API_KEY, optional Mistral-compatible base URL.
  - **goose** — Block's open-source agent as a one-shot stream-json engine, with a native mesh adapter (preview).
  - **crewai** — the CrewAI multi-agent framework as an always-on pool runtime, wired through the gateway's crewaiRouter lane (alpha, adapter #5, zero control-plane change).
- **AgentMesh seams** — runtime adapter, platform host, and scheduling policy as three pluggable surfaces; new runtimes land without control-plane changes. Idle standing processes **hibernate** and respawn **rebind-at-wake** if the envelope's model moved (never mid-stream).
- **claude-code mesh adapter + headless shim runtime** — print-mode engine and gateway binding, plus end-to-end Claude Code **API-key onboarding** in the console.

## Agents that work the board

- **Constrained lane moves** (work_item_status_change, [ADR-0025](../adr/0025-agent-status-change.md)): an agent holding custody moves its item through todo / in_progress / in_review; terminal and triage moves stay human-gated proposals.
- **Decision requests** — at least two options (9-option cap), multi-option **DecisionCards** in the inbox with letter chips, a *Recommended* badge and number-key answers; suggest_next_steps cards; a shared board-decision prompt contract in every dispatch envelope.
- **Readable progress** — two-tier comments (live italic thinking vs. one clean summary), the five-section final-comment contract on every dispatch, cross-agent comment parity (work_item_comment), and capability-aware run context so agents act via tools rather than narrate.

## Scheduling & resilience

- **SchedulingPolicy seam (P3.5)** — the mesh owns the scheduling loop, policies own the decisions; **RolePool target-N prescheduling is policy #1**, with coordinator floors, always-up exemptions, and saturation ceilings.
- **Mid-run model fallback** — on a rate-limit verdict the same run switches to its configured fallback model (SwitchModel) or pauses cleanly (PauseRun) when none resolves; wired into production dispatch.

## Console

- **LLM settings runtime-adapter tabs** — Vibe (full) and Goose (preview), Mistral provider row, Claude Code API-key onboarding.
- **Credentials Vault** — save / test / rotate / delete with write/rotate/delete audit spans and dashboards.
- **File Explorer**, **fleet-wide Project Detail**, **GitHub Kanban** polish (sub-tickets in list + Kanban views, live-run markers, treated card UI, automation settings dialogs), and markdown render/authoring QA.

## Observability

- **W3C trace propagation** across dispatch → gateway → mesh child (one trace per run).
- **ksquad.ticket.ref** span identity (resolved from ticket labels, span-attribute-only per NFR-OBS3), run.end / gateway span identity, **skill.load span proof**.
- Recall-degraded state surfaced as bounded Prometheus metrics; run summary-presence metric + missing-summary detector; per-project GitHub rate-limit telemetry.
