📝 Usage Guidelines

🎯 Message Distinction

Use agent colors (#00bcd4) for system/automated messages and human colors (#4caf50) for user-generated content. This creates clear visual hierarchy.

🔍 Consistency

Apply colors consistently across all message components: chips, avatars, message backgrounds, and text. Maintain the same color ratios.

♿ Accessibility

All color combinations meet WCAG AA standards. Ensure sufficient contrast ratios for text over backgrounds.

🎨 Brand Alignment

Message colors should complement the IsItObservable brand palette while maintaining clear distinction between message types.
