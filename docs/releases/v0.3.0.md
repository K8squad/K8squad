# Release v0.3.0

Public-image republish fixing the v0.2.0 fresh-install breakage (found in
[ISI-7264](/ISI/issues/ISI-7264) WS-1), plus everything merged to `main` since
`v0.2.0` (756 commits).

## Why

The v0.2.0 semver images were built from `6d349da1`, which predates `63b899e9`
(ISI-7109) — the commit that added the `--migrate-only` flag to
`cmd/apiserver/main.go` together with the `ksquad-migrate`
pre-install/pre-upgrade hook Job in the chart. A brand-new public adopter
following the quickstart got `BackoffLimitExceeded` on the hook with
`flag provided but not defined: -migrate-only`. Internal installs were masked:
they pin the internal registry (`10.0.0.13/k8squad:c02065db`), which carries
the flag.

## What ships

- Git tag `v0.3.0` on `main` → `build-images.yml` semver lane publishes
  `ghcr.io/k8squad/ksquad-<component>:0.3.0` (cosign signatures + SLSA
  provenance). The `:0.3.0` apiserver is built from a commit >= `63b899e9`,
  so the migrate hook's `--migrate-only` flag is defined.
- Control-plane chart (`config/helm`) `version`/`appVersion` → `0.3.0`. The
  default image tag falls back to `.Chart.AppVersion` (`_helpers.tpl`), so an
  unpinned public install resolves to `:0.3.0` images and the `ksquad-migrate`
  hook runs an apiserver that accepts `--migrate-only`.
- CRDs chart (`config/helm-crds`) `version`/`appVersion` → `0.3.0` and the
  control-plane chart's `k8squad.io/min-crds-version` annotation → `0.3.0`.
  Required: CRD schema additions since `v0.2.0` (+1008 lines across 11 files,
  incl. the new `RolePools` CRD and `Runs` additions) are additive-only.

## Notable since v0.2.0

### Agent runtimes & the AgentMesh

- Three new conformant runtimes: **vibe** (Mistral coding agent, `MISTRAL_API_KEY`,
  full console LLM tab + Mistral provider row), **goose** (Block's open-source agent,
  one-shot stream-json engine + mesh adapter, preview), and **crewai** (CrewAI as an
  always-on pool runtime through the gateway's `crewaiRouter` lane, alpha).
- **claude-code** gained a mesh adapter, a headless shim engine, and end-to-end
  API-key onboarding in the console.
- AgentMesh seams: runtime adapter, platform host, and scheduling policy as three
  pluggable surfaces — new runtimes land with zero control-plane change. Idle standing
  processes hibernate and respawn **rebind-at-wake** if the envelope's model moved.

### Agents that work the board

- Agent status-change capability — constrained lane moves + human-gated proposals
  (ISI-7219, ADR-0025).
- Suggest-next-steps capability (ISI-7218); discussion propose-gate (ISI-7221).
- Decision requests with at least two options (9-option cap), multi-option
  DecisionCards in the inbox, and a shared board-decision prompt contract.
- Two-tier comments (live thinking vs. one clean summary) and the five-section
  final-comment contract on every dispatch.

### Scheduling & resilience

- Migration gate: `--migrate-only` + `ksquad-migrate` hook (ISI-7109).
- SchedulingPolicy seam: RolePool target-N prescheduling is policy #1, with
  coordinator floors and saturation ceilings.
- Mid-run model fallback: on a rate-limit verdict the same run switches to its
  configured fallback model or pauses cleanly.

### Console & observability

- LLM settings runtime-adapter tabs (Vibe full, Goose preview, Mistral provider row),
  Credentials Vault save/test/rotate/delete with audit spans, File Explorer,
  fleet-wide Project Detail, and GitHub Kanban polish.
- W3C trace propagation across dispatch → gateway → mesh child; `ksquad.ticket.ref`
  span identity and `skill.load` spans.

## Upgrade an installed cluster

CRDs first (ADR-0002, Option B):

```sh
helm repo add k8squad https://charts.k8squad.io && helm repo update
helm upgrade --install k8squad-crds k8squad/k8squad-crds --version 0.3.0
helm upgrade k8squad k8squad/k8squad --version 0.3.0
```

Pinning `--version 0.3.0` pins `appVersion 0.3.0`, which pins the image tag to
`:0.3.0` — immutable, so the rollout (and the migrate hook) is deterministic.

## Verify

- Fresh public install no longer fails the `ksquad-migrate` hook:
  `helm upgrade --install k8squad config/helm` (no registry overrides) applies
  migrations and rolls the control plane.
- `docker run --rm ghcr.io/k8squad/ksquad-apiserver:0.3.0 --help 2>&1 | grep
  migrate-only` lists the flag.
