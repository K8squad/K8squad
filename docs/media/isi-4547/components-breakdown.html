💡 Implementation Guidelines

  • Component Structure: Use consistent class naming (ksq-activity--comment.agent/human)
  • CSS Variables: Define colors as CSS variables for easy maintenance
  • Responsive Design: Ensure components work at all screen sizes
  • Accessibility: Maintain proper contrast ratios (WCAG AA compliant)
  • Performance: Use CSS transforms for animations instead of properties that trigger repaints
  • Testing: Verify components in different light/dark modes
